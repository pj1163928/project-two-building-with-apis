{% include "partials/icon.html" with name="info" size=14 %}What's an import path?

It's the folder inside your game project where an item's files go. When the Axcenity Engine imports this pack's manifest, it downloads each item's files from the provider into its import path. Download files uses the same folders inside the zip, so unzipping it at the top of your project puts every file in the same place.

Left blank, an item goes to <type>s/<asset id>/, for example textures/red_brick_03/. Paths are relative to the project, use /, and can't climb out of it with ...

my-game/
├─ textures/red_brick_03/     blank path: the default
│  ├─ red_brick_03_diff_2k.jpg
│  └─ red_brick_03_nor_gl_2k.jpg
├─ audio/ui/                  a path you typed
│  └─ click.mp3
└─ CREDITS.txt                from Download files
