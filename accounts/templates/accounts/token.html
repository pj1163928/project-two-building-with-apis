Signing requests

Send the token in the Authorization header. Requests signed with a token don't need a CSRF token.

curl -H "Authorization: Token {{ token.key }}" \
     "{{ api_url }}?sort=rating"

curl -X POST -H "Authorization: Token {{ token.key }}" \
     -H "Content-Type: application/json" \
     -d '{"provider": "polyhaven", "external_id": "red_brick_03", "status": "testing"}' \
     "{{ api_url }}"

The list takes the library page's search, filters, sort and page. Each entry is at /api/library/<id>/, where GET reads it, PATCH or PUT changes its notes, rating and status, and DELETE removes it from your library and from your packs.
